Backup

Exports every table in the database (cement ledger, invoices, customers, and Iron & Steel stock), encrypts it, and emails it as an attachment. Nothing runs on a schedule — this only happens when you click the button below.

The file cannot be opened without the backup passphrase. Whoever set this up has it; ask them if you need to restore a backup and don't have it.
